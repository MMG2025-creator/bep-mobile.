Fonctionnement du Coach

Le Coach IA BEP s’appuie sur Google Gemini 3.5 Flash (gemini-3.5-flash), un modèle rapide et polyvalent. Les échanges passent par le service sécurisé de BEP : aucune clé API personnelle n’est nécessaire.

Si le service Gemini est momentanément indisponible, le moteur local BEP reste disponible.

INTELLIGENCE ARTIFICIELLE

Ton Coach IA BEP

Coach local

Le Coach IA BEP intégré est utilisé automatiquement lorsqu’il est disponible. Aucune clé API personnelle ni aucun crédit de fournisseur externe ne sont nécessaires.

Le moteur local reste disponible pendant l'activation du service IA.

Le moteur local n’utilise aucun quota API.

Connexion d’un fournisseur IA externe (option avancée)

Facultatif : réservé aux utilisateurs qui disposent de leur propre clé API. Les appels seront facturés par le fournisseur choisi. Les données financières envoyées à ce fournisseur lui seront transmises.

Mon profil

Mes données et ma confidentialité

Les informations financières sont conservées dans le stockage privé de ce navigateur sur ce téléphone. Effacer les données du navigateur ou désinstaller le navigateur peut les supprimer.

L'export est chiffré avec AES-GCM et une dérivation de clé PBKDF2. Conserve ton mot de passe séparément : sans lui, la sauvegarde ne pourra pas être restaurée.

Compte et session

Ferme ta session BEP sur cet appareil. Tes données enregistrées sur ton compte ne sont pas supprimées.

Méthodes de connexion

Associe Google à ton compte BEP. Pour un compte e-mail, confirme d’abord ton mot de passe. Google doit confirmer la même adresse e-mail que ton compte BEP.

Suppression du compte

Supprime définitivement ton compte BEP, ton profil, tes données financières, tes achats, tes objectifs et les sessions associées. Cette action est irréversible.
